# Evidencias BeachPlanner

Esta carpeta contiene las evidencias simuladas utilizadas para validar las funcionalidades principales del proyecto BeachPlanner.

## Archivos incluidos

### Evidencia_Registro.png
Representa el registro exitoso de un nuevo usuario dentro de la plataforma.

### Evidencia_Pago.png
Representa el registro y confirmación de un pago realizado por un participante del paseo.

### Evidencia_Reserva.png
Representa la confirmación de una reserva de hospedaje para el paseo.

## Objetivo

Las evidencias fueron elaboradas con fines académicos para apoyar el Plan de Pruebas del Sistema y demostrar visualmente el resultado esperado de las funcionalidades principales propuestas para BeachPlanner.

## Relación con el Plan de Pruebas

Estas evidencias corresponden a los siguientes casos de prueba:

- CP-01: Registro de Usuario.
- CP-05: Registro de Pago.
- CP-06: Gestión de Reservas.
