# Descripción del Proyecto

BeachPlanner es una propuesta de aplicación web diseñada para facilitar la organización de paseos grupales a la playa.

La plataforma busca centralizar la gestión de participantes, pagos, reservas y actividades en un único sistema, mejorando la organización y comunicación entre los integrantes del grupo.

---

# Objetivo General

Diseñar una solución tecnológica que permita organizar paseos grupales de manera eficiente mediante la gestión de participantes, pagos, reservas y cronogramas de actividades.

---

# Funcionalidades Propuestas

* Registro de usuarios.
* Inicio de sesión.
* Creación de paseos.
* Gestión de participantes.
* Registro de pagos.
* Gestión de reservas.
* Cronograma de actividades.
* Notificaciones.
