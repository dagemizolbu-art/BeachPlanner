# Diagramas BeachPlanner

Esta carpeta contiene los diagramas elaborados para el proyecto BeachPlanner.

## Contenido

- Diagrama_BeachPlanner.png

## Descripción

El diagrama BPMN representa el flujo principal del proceso de organización de un paseo utilizando la aplicación BeachPlanner.

El proceso incluye:

- Registro de usuarios.
- Inicio de sesión.
- Creación del paseo.
- Gestión de participantes.
- Registro de pagos.
- Gestión de reservas.
- Creación del cronograma.
- Confirmación de la organización del paseo.

## Herramienta utilizada

- Bizagi Modeler
